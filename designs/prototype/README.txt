Arrival Engine — surfaces prototype

Open "Arrival Engine - Prototype.dc.html" in a browser.

Keep the folder together: the shell loads each surface from handback/render/, and those load
handback/static/arena.css. That is the point of this build — the frames render the real stylesheet
and the real template markup, so the prototype and the drop-in repo files cannot drift.

Twelve surfaces, 390x844: room, ready, why, unknown-coverage, cold-trail, no-strong-match,
empty-room, withheld, ambiguous, ingesting, scoring, room-empty.

For a single-file, fully editable version of the same design, use the Screens export instead.
